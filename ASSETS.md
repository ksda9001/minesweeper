# Bundled assets

All runtime assets are local; no external texture, font, audio, or shader request is needed while playing.

Photographic textures and environment from [Poly Haven](https://polyhaven.com/license), CC0:

`clover-patch.glb`, `daisy.glb`, and `branch.glb` are original meshes created through Blender MCP; the editable scene is `assets-source/woodland.blend` and its reproducible modeling script is `woodland_models.py`.
Grass blade geometry, woven flag props, explosion particles, UI icons, and synthesized sounds are generated by project code.
`branch-frame.png` is an earlier transparent decorative UI asset generated with OpenAI ImageGen.

`branch-relief.png`, `rough-planks.png`, `turf-detail.png`, `soil-relief.png`, `counter-cards.png`, and `clover-token.png` were generated with OpenAI ImageGen using the user's supplied visual reference. The outer bezel and timber panels use the shared Babylon engine, segmented relief meshes and height-derived tangent normals; their lighting responds to device tilt. This is textured relief, not a complete geometric reconstruction of the pictured branches. Counter cards and the clover token remain raster UI assets.

The game cells preserve soil-relief.png and its height-derived normal map. Square patches meet at shallow grooves and crop the artwork's outer 4%, independent of screen aspect ratio. The continuous background uses the same artwork's unframed interior, blending randomly rotated and offset samples instead of mirrored repeats. Its relief lighting follows the blended soil detail.

`numbers.glb` contains original extruded, beveled digits made by `assets-source/numbers.py`; its editable Blender scene is `numbers.blend`. The modeling script uses the installed Windows Georgia Bold font. These number meshes are bundled in the game, not redistributed as a font.
`mine.glb` is an original exterior disc mine model with a stamped lid, rolled rim, rivets, carrying loop, and weathered CC0 painted-metal PBR material. `assets-source/mine.py` reproduces it and `mine.blend` contains the editable scene with packed textures. It is a visual game prop with no functional or internal mechanism.

WebGPU shader tools are bundled from Babylon.js CDN: `glslang.js/.wasm` and `twgsl.js/.wasm`.
Babylon.js is Apache-2.0; glslang and Tint retain their upstream licenses in `THIRD_PARTY_LICENSES/`.
Photographic textures currently use 1K JPEGs; convert to KTX2 when texture bandwidth or memory measurements warrant it.

The skeuomorphic launcher artwork in assets-source/app-icon.png was generated with OpenAI ImageGen for this game. assets-source/icons.py packages it for Android adaptive and legacy launchers, Windows ICO, and Web PNG icons. The red cloth uses procedural warp/weft normal detail and folded ribbon geometry. The mine retains the CC0 green_metal_rust maps, with separate enamel clearcoat and reflective worn-steel edges.
