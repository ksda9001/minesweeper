# 微软商店提交材料

产品：**realistic minesweeper**

商店包版本：**1.0.0.0**，对应游戏源码版本 **0.1.7**。

## 使用顺序

1. 打开这个产品在 Partner Center 中的提交页面，产品类别选游戏，子类别建议益智类（Puzzle & trivia）。设备仅选 PC，架构为 x64。定价、可用市场和发布时间由你在后台决定。
2. 在“包”页面上传 `realistic-minesweeper-1.0.0.0-x64.msix`。这份包使用了你提供的微软产品身份，随包带有固定版 WebView2。它是商店上传包，微软审核通过后签名；不要用双击安装是否成功来判断这份未签名上传包，也不要上传旧 NSIS 安装器。
3. 添加简体中文 **zh-CN**、英语 **en-US** 和日语 **ja-JP** 三个商店语言。日语在“额外商店语言”中添加。游戏内部界面目前支持中文、英文；日语宣传资料已注明这一点。
4. 各语言的 `listing-语言.txt` 可逐项复制到简介、描述、功能、关键词和截图标题。第一版上架时，“此版本中的新增功能”留空。产品名三种语言均使用你已预留的 **realistic minesweeper**；如要改成中文或日文名称，先在后台预留对应名称。
5. 按语言上传 `screenshots/语言/01…04.png`，每张都是 **1920×1080** 的真实游戏画面。日语页使用真实英文游戏画面，配日文截图说明。
6. 游戏商店 Logo 使用 `artwork/语言/poster-720x1080.png`（2:3 海报）和 `box-1080x1080.png`（方形封面）。共享 `hero-1920x1080.png` 是不含产品标题的横版主视觉；`AppTileIcon.png` 是 300×300 图标。未制作可选视频预告片。
7. 隐私政策地址填：`https://github.com/ksda9001/minesweeper/blob/main/store/privacy.md`；支持地址填：`https://github.com/ksda9001/minesweeper/issues`。隐私政策含中、日、英三语。提交前确认这些公开网页可访问。
8. 完成 IARC 年龄分级问卷。游戏有地雷和棋盘爆炸，没有人物、动物、伤亡、血液或血腥画面；请按问卷具体问题如实填写，不能直接假定所有暴力问题都选否。评级由 IARC 生成。
9. 审核备注可直接复制 `certification-notes.txt`。其中已解释 `runFullTrust`：用于普通权限运行 Tauri/Win32 游戏与 WebView2，没有管理员提权、驱动或系统服务。
10. 阅读 `validation-report.md`。本次 Windows 应用认证工具已以管理员权限完成完整检查，结果 **PASS**；`certification/` 附有 XML 和 HTML 报告。如需重新验证，附带 `run-certification.ps1` 可从管理员 PowerShell 执行。

## 安装和验证

商店用户会获得微软签名后的安装包。开发测试可在开启开发者模式的电脑注册 `package-layout/AppxManifest.xml`；未签名 MSIX 不是面向用户直接分发的安装器。

详细重建和认证命令在 [README.md](README.md) 中。只宣称 x64 Windows PC 支持；没有将 Android 包、Xbox 或 ARM64 加入本次商店提交。

本次准备不代替你在后台决定价格、市场、年龄评级或点击最终发布。商店是否通过认证由微软审核决定。
