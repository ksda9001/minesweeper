## Build the Store package again

Install Node/pnpm, Python/Pillow, Rust MSVC and Windows SDK. Extract an official **x64 Fixed Version** WebView2 runtime from the [Microsoft download page](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Keep all runtime files; do not substitute the Evergreen bootstrapper.

```powershell
pnpm install --frozen-lockfile
powershell -NoProfile -ExecutionPolicy Bypass -File store/build-msix.ps1 `
  -RuntimePath 'C:\build\Microsoft.WebView2.FixedVersionRuntime.VERSION.x64' `
  -OutputDirectory 'C:\build\store-release-1'
```

Use a fresh output directory. The script verifies Microsoft's runtime signature, builds Tauri with the fixed runtime setting, exports existing icon artwork, copies licenses/privacy, and invokes Windows SDK MakeAppx with schema validation and SHA-256. The checked-in manifest uses the exact Partner Center identity. The fourth version component must stay **0** for Store packages; increase the preceding components for updates. Refresh the fixed runtime for security updates and resubmit the package; it does not self-update.

The ignored `src-tauri/WebView2` junction is retained as the build cache. A later build must use the same runtime target or explicitly replace this cache first; the script never removes a different existing path.

For development, register the generated `package-layout\AppxManifest.xml` using `Add-AppxPackage -Register` on a computer with Developer Mode enabled. A Store upload package is intentionally unsigned; outside-Store distribution needs a trusted signing certificate. Do not distribute a test certificate/private key with the submission.

Run the certification kit from an **administrator PowerShell in your interactive account**. It can launch and close the test game. `run-certification.ps1` registers this specific layout and runs the Desktop Bridge workflow. It does not enable Developer Mode or change certificate trust. Review the generated XML/HTML rather than treating a process exit as a Store certification decision.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File store/run-certification.ps1 `
  -LayoutPath 'C:\build\store-release-1\package-layout' `
  -ReportDirectory 'C:\build\wack-report'
```
